# Astra Child Umbral

Child Theme personalizado para Umbral - Tienda de Ropa.

## Instalación

1. Asegúrate de que el tema padre **Astra** esté instalado y activo
2. Sube este folder `astra-child-umbral` a `/wp-content/themes/`
3. Activa el tema desde **Apariencia → Temas**

## Características

- ✨ Paleta de colores personalizada (Negro + Dorado)
- 🔤 Google Fonts: Playfair Display (títulos) + Inter (cuerpo)
- 🛒 Soporte completo para WooCommerce
- 📱 Responsive y optimizado para móviles
- 🎨 Personalización de bloques Gutenberg

| Dorado Sofisticado | #c9a962 | Acento |
| Dorado Claro | #d4b87a | Hover |
| Blanco | #ffffff | Fondo |
| Gris Texto | #333333 | Texto |

## Archivos

- `style.css` - Estilos personalizados
- `functions.php` - Funciones y configuración
- `screenshot.png` - Imagen del tema (recomendado: 880x660px)

## Requisitos

- WordPress 5.0+
- Tema padre: Astra
- PHP 7.0+

## Personalización

Desde **Apariencia → Personalizar** puedes:

- Cambiar logo y favicon
- Ajustar colores
- Modificar tipografías
- Configurar header y footer
- Ajustar espaciados
